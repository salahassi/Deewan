# ديوان الحقباني — بروتوتايب تفاعلي

واجهة عربية من اليمين إلى اليسار للويب والموبايل، تشمل شخصيات الزائر والمنتسب والمشرف والأدمن.

## الميزات

- التسجيل برقم الجوال، OTP تجريبي `123456`، ثم موافقة الإدارة.
- مجالس مرتبطة بقسم أو أكثر، بحث وفلاتر الكاتب والتاريخ والحالة والترتيب.
- محرر نص غني للمواضيع والصفحات: عناوين وقوائم واقتباسات وروابط وتنسيق.
- تعليقات، دردشة عامة وخاصّة مع الإدارة، وصلاحيات مشرفين حسب الأقسام.
- رسوم شهرية وحوالات أوفلاين، رفع الوصل، قبول أو رفض، تحصيلات وقيود العمليات.
- لقاءات وبث على منصات خارجية مع سجل فتح الرابط وتأكيد انعقاد يدوي.
- إعدادات الهوية واسم الموقع والرئيسية والشعار والأيقونة والألوان والتواصل.
- إعدادات SEO وعنوان المتصفح والوصف والرابط الأساسي وصورة المشاركة ومعاينة البحث.
- شريط إخباري متحرك: إضافة وترتيب وتفعيل الأخبار، روابط، اتجاه وسرعة وإيقاف.

## التشغيل

يتطلب Node.js 22.13 أو أحدث.

```sh
npm install
npm run dev
npm run typecheck
npm run build
```

ينتج البناء مجلد `docs/` جاهزًا لـGitHub Pages. إعداد `base` في `vite.config.ts` هو `/Deewan/`؛ عدّله إن تغير اسم المستودع.

## النشر على GitHub Pages

ارفع هذا المشروع إلى مستودع عام باسم `Deewan`. في `Settings → Pages` اختر `Deploy from a branch` ثم `main` ومجلد `/docs` واحفظ. ملفات البناء و`.nojekyll` موجودة في `docs`، فلا يحتاج النشر إلى خادم أو تثبيت dependencies على GitHub.

عند تعديل المصدر، نفّذ `npm run build` وارفع المصدر ومجلد `docs` معًا.

## حدود البروتوتايب

هذه محاكاة وليست نظام إنتاج. يمكن تغيير الشخصية من شريط العرض بدون تسجيل حقيقي. البيانات والإعدادات محفوظة محليًا في المتصفح؛ ملفات الوصولات في IndexedDB. التعليقات والدردشة تتزامن بين تبويبات المتصفح نفسه، ولا تتشارك بين أجهزة المستخدمين. لا تُرسل SMS ولا يُنفّذ دفع أو بث داخل التطبيق.

تغييرات SEO من الأدمن معاينة محلية؛ HTML المنشور يحمل القيم الافتراضية. التطبيق `noindex` افتراضيًا لأنه يستخدم بيانات توضيحية. فتح رابط خارجي يسجل الفتح فقط ولا يثبت الحضور أو بدء البث.

## التحقق

تم فحص TypeScript والبناء، وحفظ إعدادات الاسم والرئيسية وSEO والأخبار والألوان، والنشر في قسمين بنفس التعليقات، وفلاتر المجالس، والنص الغني للمواضيع والصفحات، وواجهة الموبايل. مسارات العضوية والإشراف والرسوم والدردشة والبث متاحة للتجربة من الشخصيات المختلفة.
